# v1.1.0｜生成前控制与返工边界

依据两张真人图实际使用：四次编辑中，两张初版均出现分身偏高；街拍初版裤子有渐变，树下初版格纹过密、眼睛较精致。加强相对画面尺度、简化五官和色块后改善。只能支持针对这些失败优化，不证明短 Prompt 一定优于长 Prompt，也不证明可以零返工。

## 1. 先算位置，再调用模型

不把源图像素坐标直接当最终输出坐标。模型会输出不同分辨率，所有控制都使用原构图的 0～1 比例。

测量真人头 / 头饰顶 y_top、最低鞋底 y_bottom，除以原图高度。站立或坐姿选对应 scale.basis；角色计划高度 = (y_bottom − y_top) × 目标比例。先选真实地面 / 座位决定角色 bottom，再算 top = bottom − height。

不要同时写相互冲突的“65%真人高”“占一半画面”和任意 head top。生成器由同一组字段算出唯一框。用户想更大或前景透视例外时明确 custom，不偷改默认比例。

街拍样本：真人 top≈0.358、bottom≈0.955，目标 r=0.64，角色高≈0.382 个画面；bottom=0.95 时 top≈0.568。可以额外描述“头明显低于真人肩部”，但必须先确认这句话与计算和姿态一致，不能对所有照片硬套。

树下样本：真人 top≈0.378、bottom≈0.897，目标 r=0.67，角色高≈0.348；bottom=0.90 时 top≈0.552。只用近草地支持它，不混同远处草坪。

左右位置用 center_x 和 width 计算 left / right。留边距，不挡脸与关键穿搭；文字描述的安全区必须和数值框一致。数值只能辅助指令，脚本不会检查实际照片内容。

## 2. 两种 Prompt 的用途

- concise：实际编辑默认。顺序为摄影保护 → 角色框 → L1 身份 → 动作表情 → 平涂 → 支撑。一般只包含对这张图起决定作用的信息。
- full：21 区块完整设计与回查，不作为普通生成时的默认长输入。用户只要完整 Prompt 时按请求输出 full。

不要先发 full，再在最后加一段冲突的修订要求。更新 brief，重新编译，让一次调用只有一个比例、一个位置、一个线稿 / 表情语法。

## 3. 收紧绘制预算，而不是增加精致度

默认：平色、深轮廓、少量内线；眼睛点 / 小椭圆，微鼻与短嘴。墨镜按原图保留。选择带眼白 / 少量腮红的手绘语法时也需简单，不能自动变成装饰大眼动漫。

只保留 L1 / 有用 L2。小 Logo / 字体 → 几个色块或短线；微格纹 → 少量疏线或省略；牛仔 / 布料纹理 → 无；裤褶 → 简短线而不是深浅渐变。不能为了装下这些细节把人画大。同批固定头身、线稿、眼睛和色块语法，允许不同的脸型 / 发型 / 姿态，不能固定一张模板脸。

## 4. 保真路径是工具选择问题

生成前区分：用户要视觉上保持原图，还是明确要求未编辑区逐像素不变。

有局部编辑 / 保护区域 / 合成工具时，按其真实能力保护原人物与背景。当前内置 image_gen 没有暴露像素锁定保证，不能把 preserve 或坐标框当真实 mask 参数。普通编辑可在严格提示后执行，但交付须诚实说明局部重绘边界。

明确要求绝对保真且工具无法满足时，不能交付全图生成结果并声称原图未变。说明能力缺口，交付可用的角色设计 / Prompt，或在适合且用户范围允许时生成透明角色素材供原图图层合成。没有合成能力不能声称这条路径已完成，也不擅自切换付费 API、安装软件或上传外部服务。

“原件未覆盖”和“成图摄影像素未改”分开验收。

## 5. 首轮检查优先级

先检查真人 / 环境明显漂移，再检查尺寸和脚 / 座面，之后检查 L1、二维属性与细节。先处理影响作品成立的错误。

记录实际画面高度比与目标比例，建议目标误差带约 ±0.05；这是人工设计工作带，不是参考作者标准。明显接近同高、超过既定安全区、挡脸、漂浮、错 L1 或写实渐变是必须处理的失败。小幅比例偏差若仍有主次、支撑和风格，可记录偏差并交付，不为几百分点重复重绘整图。

不要通过删除配饰或随便换衣色来掩盖尺度错误。不要把换分辨率产生的边界误差算成身份改变；脸、眼神、轮廓或小字真实漂移仍应检查。

## 6. 修订必须限制变化范围

修尺寸：保留 L1 / 线稿 / 配色，只调整框与落脚；修平涂：保留比例 / 姿态 / 位置，去渐变和纹理。一次只聚焦主要问题。

有可用局部编辑能力时只修插画区域。没有时，仍以原始照片为摄影基底，可附选定插画作风格参考但必须明确图片角色；不能让模型把上轮漂移照片当新基底。尺寸 / 画法修正最多两轮，禁止无限“再精致一点”的生成链。

这套控制用于减少可预防返工，实际首轮成功率需后续照片验证。
