# 12 张参考图｜视觉机制分析

依据：用户按序提供的 12 张 JPEG，已逐张查看。文件没有原始拍摄流程、角色绘制过程或可核实作者信息。本文分析视觉设计，不推断作者工具、AI / 人工作者身份、实际焦段或传播表现。

## 共同机制

这不是一个固定角色风格，而是一个稳定的“识别编码”系统：从真人的头发、衣着、辨识物中提取组合，用另一种媒介重复编码，再用动作关联与空间位置让两者像同一时刻的两个版本。

真人层提供事实感，插画层提供情绪与轮廓记忆。头发 / 穿搭像，脸不必像；动作可以变，身份不能变；材质可以不同，支撑与深度不能乱。角色在叙事上是陪伴者，在身份上是本人分身。以 Photo Alter Ego 命名最贴近这些边界。

## 共同语法与非共同特征

**可靠共同语法**：本人穿搭信息压缩、二维轮廓、低材质感、真人摄影保持可辨识、角色邻近、动作 / 气质关联。

**变化项**：粗细线、眼白 / 点眼、腮红、比例、色相风格化、近远、人物位置、动作同步程度、阴影。图 2、6、7部分有笔迹 / 纹理，图 11轮廓很顺滑；不能把“完全无纹理”和“每条线抖动”列为原图共同事实。

**不可从图片确定**：原作者是否保留摄影像素、实际制作软件 / 模型、镜头规格、真实生成步骤、准确色板数量、阴影绘制图层和传播指标。

**参考中可改进而不盲学的地方**：图 1接触较弱；图 9墨镜位置有自由改编；图 10新增插画家具；图 11、12边界较挤。Skill 以用户未来目标为准，默认提升支撑和原图保护，不复制这些例外。

## 为什么像插画师随手画，而不是精致 AI 卡通

不是单靠线条抖动。重要的是明显的信息删减：白裙无微皱、工装裤无牛仔颗粒、头发是轮廓和卷线、圆点 / 条纹是符号、脸用少数几笔，人物情绪与行为也经过选择。二维角色没有试图解释每个光源和材质，摄影却保留复杂环境，两者因此各自成立。

## 四种模式怎样转成生成变量

用户指出的“同步动作 / 同穿搭不同动作 / 情绪映射 / 场景互动”准确描述了观察角度，但它们不是四个互斥标签。实现为两轴：

- 肢体关系：Mirror / Complementary / Interactive。
- 表情关系：同步 / 轻放大 / 克制变奏。

图 9 = Mirror + 情绪放大；图 12 = Complementary + 共座互动 + 酷感放大。允许组合，才能避免一个模板走到底。参考没有明确真人与卡通牵手的证据，牵手只是未来在接触条件允许时的可选设计。

## 从分析到稳定方法

读取真实信息 → 选择识别锚点 → 三层压缩 → 选择动作与情绪 → 找安全区 / 支撑面 → 定尺度 / 遮挡 → 统一线色 → 编辑和对照检查。

稳定的是这些决策顺序与验收门槛，不是某张脸、某个角色、某个站位或每次生成完全一致。
